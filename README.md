# Hotspot Chat 📶

মোবাইল ডেটা বা ইন্টারনেট ছাড়াই, শুধু **মোবাইল হটস্পট** ব্যবহার করে গ্রুপ চ্যাট, প্রাইভেট মেসেজ, আর ছবি পাঠানোর অ্যাপ।

## এটা কীভাবে কাজ করে (কনসেপ্ট)

1. একজন (ধরুন **হোস্ট**) তার ফোনের **Mobile Hotspot** চালু করে দেবে।
2. বাকি সবাই সেই হটস্পটের WiFi-তে কানেক্ট করবে (ইন্টারনেট থাকুক বা না থাকুক, সমস্যা নেই — এটা শুধু একটা লোকাল নেটওয়ার্ক হিসেবে কাজ করবে)।
3. হোস্টের ফোনে এই ছোট সার্ভারটা চালু থাকবে (Termux দিয়ে)।
4. বাকিরা তাদের ফোনের ব্রাউজারে (Chrome ইত্যাদি) হোস্টের **লোকাল IP** টাইপ করে ওয়েবসাইটের মতো চ্যাট অ্যাপে ঢুকে যাবে।
5. যেহেতু সব ডেটা হটস্পটের ভেতরের নেটওয়ার্কেই থাকে, **কোনো মোবাইল ডেটা বা ইন্টারনেট খরচ হয় না** — এমনকি হোস্টেরও না।

## হোস্টের ফোনে সেটআপ (Android + Termux)

1. Play Store থেকে **Termux** ইনস্টল করুন (Google Play বা F-Droid থেকে — F-Droid ভার্সনটা বেশি আপ-টু-ডেট থাকে)।
2. Termux ওপেন করে এই কমান্ডগুলো একে একে চালান:
   ```
   pkg update -y
   pkg install nodejs -y
   ```
3. এই প্রজেক্ট ফোল্ডারটা ফোনে নিয়ে যান (যেমন Google Drive / USB / Bluetooth দিয়ে), অথবা Termux থেকেই ফাইলগুলো তৈরি করুন। ধরে নিচ্ছি ফোল্ডারটা আছে `/sdcard/hotspot-chat` এ। Termux-এ:
   ```
   termux-setup-storage
   cp -r /sdcard/hotspot-chat ~/hotspot-chat
   cd ~/hotspot-chat
   npm install
   ```
4. এখন **Mobile Hotspot চালু করুন** (Settings > Hotspot & Tethering)।
5. সার্ভার চালু করুন:
   ```
   npm start
   ```
6. টার্মিনালে একটা ঠিকানা দেখাবে, যেমন:
   ```
   http://192.168.43.1:3000
   ```
   এই ঠিকানাটাই বাকিদের দিতে হবে।

## বাকিদের যা করতে হবে

1. হোস্টের হটস্পট WiFi-তে কানেক্ট করুন (পাসওয়ার্ড হোস্ট থেকে নিন)।
2. যেকোনো ব্রাউজার (Chrome/Firefox) খুলুন।
3. উপরে ধাপ ৬-এ দেখানো ঠিকানাটা (যেমন `http://192.168.43.1:3000`) টাইপ করে Enter দিন।
4. নিজের নাম দিয়ে "ঢুকুন" চাপুন।
5. ব্যাস — এখন গ্রুপ চ্যাটে মেসেজ দেওয়া যাবে, বাম পাশের লিস্ট থেকে যেকোনো একজনকে ক্লিক করে তাকে একা মেসেজও (প্রাইভেট চ্যাট) দেওয়া যাবে, ছবি পাঠানো যাবে ক্যামেরা আইকনে ক্লিক করে।

## ফিচার

- ✅ গ্রুপ চ্যাট (হটস্পটে যারা যারা আছে সবাই দেখবে)
- ✅ একজনকে একা মেসেজ (প্রাইভেট চ্যাট)
- ✅ ছবি পাঠানো (ছবি অটোমেটিক ছোট করে পাঠানো হয় যাতে দ্রুত যায়)
- ✅ কে অনলাইন আছে তার লিস্ট, live আপডেট হয়
- ✅ টাইপিং ইন্ডিকেটর ("... লিখছে")
- ✅ ১০০% লোকাল — কোনো ইন্টারনেট বা ডেটা লাগে না

## সীমাবদ্ধতা যা জেনে রাখা ভালো

- হোস্টের **হটস্পট বন্ধ করলে বা সার্ভার বন্ধ হয়ে গেলে** চ্যাট বন্ধ হয়ে যাবে। এটা কোনো ক্লাউড সার্ভিস না — শুধু লোকাল নেটওয়ার্ক।
- মেসেজ হিস্টোরি সার্ভার মেমোরিতে থাকে না (রিফ্রেশ দিলে পুরনো মেসেজ চলে যাবে) — চাইলে এটা পরে ডাটাবেজ যোগ করে স্থায়ী করা যায়।
- হটস্পটে সাধারণত একটা লিমিট থাকে কতজন কানেক্ট করতে পারবে (ফোন ভেদে ভিন্ন, সাধারণত ৮-১০ জন)।
- একই হটস্পটের রেঞ্জের বাইরে গেলে (দূরে চলে গেলে) কানেকশন কেটে যাবে, যেহেতু এটা WiFi রেঞ্জ-নির্ভর।

## অন্য বিকল্প (হোস্ট ফোনে Termux না চালাতে চাইলে)

- একটা পুরনো ল্যাপটপ/কম্পিউটারে এই একই সার্ভার চালিয়ে সেই কম্পিউটারকে হটস্পট বানানো যায় — ল্যাপটপ থেকে হটস্পট শেয়ার করলে ব্যাটারি বেশি লাগবে না ফোনের।
- ভবিষ্যতে React Native দিয়ে সত্যিকারের APK বানানো যায় যাতে ব্রাউজার ছাড়াই সরাসরি অ্যাপ থেকে চালানো যায়। এই ভার্সনটা প্রোটোটাইপ/MVP হিসেবে দ্রুত টেস্ট করার জন্য বানানো।
